# Correctness corpora

Input text for the logit comparisons of the Correctness Flow in `AGENTS.md`. Each file is long enough for one `llama-perplexity` run at `-c 2048` (at least 2 x 2048 tokens) without repetition, and the four together cover `-c 16384`. Counts with the `qwen35` vocab (`models/ggml-vocab-qwen35.gguf`):

| File | Tokens | Content |
|---|---|---|
| `correctness-prose.txt` | 5263 | natural English prose, three styles |
| `correctness-code.txt` | 7228 | C++, Python, GLSL, TypeScript, CMake, shell |
| `correctness-structured.txt` | 8300 | JSON, YAML, CSV, TOML, a Markdown table, GBNF |
| `correctness-numeric.txt` | 13236 | integers, primes, tables, scientific and hex values, arithmetic |

Do not edit these files: results are only comparable across runs with the same bytes. Record their sha256 with each run.

## Sources

The text is real, not generated by a model: model text is too easy to predict and hides small numeric errors.

- **prose**: public-domain books from Project Gutenberg, with the Project Gutenberg header and license removed, cut at paragraph boundaries and converted to ASCII:
  - #10849, O. F. Walton, *Saved at Sea: A Lighthouse Story* (1887), from chapter IV;
  - #52817, F. A. Talbot, *Lightships and Lighthouses* (1913), from chapter VII;
  - #70176, J. Kennedy, *The History of Steam Navigation* (1903), from chapter X.
- **code**: excerpts of this repository (MIT): `src/llama-sampler.cpp`, `gguf-py/gguf/gguf_reader.py`, `ggml/src/ggml-vulkan/vulkan-shaders/soft_max.comp`, `tools/ui/src/lib/utils/api-fetch.ts`, `ggml/src/ggml-hip/CMakeLists.txt`, `scripts/compare-commits.sh`. They are a frozen copy: later changes to these files do not change the corpus.
- **structured**: excerpts of this repository (MIT): `CMakePresets.json`, `tools/ui/package.json`, `.github/workflows/build-cpu.yml`, `docs/ops/CUDA.csv`, `pyproject.toml`, the table of `docs/ops.md` (symbols replaced by `yes`, `no`, `partial`), `grammars/json.gbnf`, `grammars/c.gbnf`.
- **numeric**: generated with a fixed seed by this script (Python 3):

```python
import random

r = random.Random(1151)
out = []

out.append("Integer boundaries:")
out.append(" ".join(str(v) for e in range(0, 33) for v in (2**e - 1, 2**e, 2**e + 1)))
out.append("")
out.append("Signed boundaries:")
out.append(" ".join(str(v) for v in (-2**31, -2**15, -2**7, -1, 0, 1, 2**7 - 1, 2**15 - 1, 2**31 - 1, 2**63 - 1)))
out.append("")

out.append("Primes below 600:")
out.append(" ".join(str(n) for n in range(2, 600) if all(n % d for d in range(2, int(n**0.5) + 1))))
out.append("")

out.append("Sensor log (id, time, temperature C, pressure hPa, humidity %, voltage V):")
t = 0
for i in range(120):
    t += r.randint(1, 90)
    out.append(f"{1000 + i}, {t // 3600:02d}:{t // 60 % 60:02d}:{t % 60:02d}, {r.uniform(-20, 45):.2f}, "
               f"{r.uniform(950, 1050):.1f}, {r.randint(5, 100)}, {r.uniform(3.0, 4.2):.3f}")
out.append("")

out.append("Scientific notation:")
out.append(" ".join(f"{r.uniform(1, 10) * 10 ** r.randint(-12, 12):.6e}" for _ in range(60)))
out.append("")

out.append("Hexadecimal words:")
out.append(" ".join(f"0x{r.getrandbits(32):08x}" for _ in range(64)))
out.append("")

out.append("Arithmetic:")
for _ in range(80):
    a, b = r.randint(-9999, 9999), r.randint(1, 999)
    op = r.choice("+-*/")
    res = {"+": a + b, "-": a - b, "*": a * b, "/": round(a / b, 4)}[op]
    out.append(f"{a} {op} {b} = {res}")
out.append("")

out.append("Ledger (date, account, debit, credit, balance):")
bal = 10000.00
for i in range(70):
    d = r.choice([True, False])
    amt = round(r.uniform(0.5, 2500), 2)
    bal = round(bal - amt if d else bal + amt, 2)
    out.append(f"2026-{r.randint(1, 12):02d}-{r.randint(1, 28):02d}, {r.randint(100000, 999999)}, "
               f"{amt if d else 0:.2f}, {0 if d else amt:.2f}, {bal:.2f}")
out.append("")

out.append("Matrix 12x12 (float16 range):")
for _ in range(12):
    out.append(" ".join(f"{r.uniform(-65504, 65504):.3f}" for _ in range(12)))

print("\n".join(out))
```
